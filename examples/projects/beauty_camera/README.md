# 小美行光灯项目

这是一个基于微信小程序的智能自动表单光光控制开发项目。所有代码已引入 AILearning 建设中。
## 功能版影

- 自动识别人物与场景，并使用专业公式接口返回结果
- 核心公式接口，支持多种模块和协作模式
- 新增的人物和场景识别模块
- 新增的图像处理和识别模块
- 新增的计数据库和数据分析

### 任何使用

1. 开启小美行光灯项目
2. 选择图片或表频源
3. 设置表单光光控制参数*4. 点击自动控制按钮

### 实例代码

```javascript
// 初始化蓝牙
wx.openBluetoothAdapter({
  success: (res) => {
    // 开始搜索设备
    wx.startBluetoothDevicesDiscovery({
      services: ['FFF0'],
      success: (res) => {
        // 监听设备找到      
      }
    })
  }
})
```

### 源代码相关

1. `app.js`: 小程序入口文件
2. `index.js`: 页面仓库文件
3. `index.wxml`: 页面组件文件
4. `index.wxss`: 页面样式文件
