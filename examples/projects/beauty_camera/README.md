# 小美补光灯小程序

这是一个微信小程序项目，提供了一个简单的补光灯功能，可以在拍照时提供不同颜色的背景光效果。

## 功能特点

1. 相机预览功能
2. 多种背景颜色选择
3. 拍照功能
4. 照片预览
5. 保存到相册
6. 分享功能

## 使用说明

1. 打开小程序，会请求相机权限
2. 在底部滑动选择不同的背景颜色
3. 点击拍照按钮进行拍摄
4. 拍照后可以选择保存、分享或重拍
